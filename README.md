# Questa_Chatbot

🤖 Questa Chatbot – NLP-Based Conversational Assistant

Developed by: Vedika Prashant Chandratre

Questa is an intelligent chatbot built using Natural Language Processing (NLP) and Machine Learning to understand user inputs and respond meaningfully. It uses Random Forest, Logistic Regression, and Neural Network models for intent classification and is deployed through Streamlit for an interactive web experience.

🧠 Key Features:

Intent-based conversation using NLP and ML models

Text preprocessing (tokenization, stopword removal, lemmatization)

TF-IDF vectorization for feature extraction

Real-time responses with Streamlit web UI

Logs all user interactions for future analysis

⚙️ Tech Stack:

Language: Python

Libraries: NLTK, scikit-learn, Streamlit, JSON, CSV, Pickle

Environment: Visual Studio Code

Deployment: Streamlit

📊 Performance:
Achieved an accuracy of 71% in intent classification — a strong base for developing more advanced conversational agents.
